# Мини‑Склад (учебная конфигурация 1С)

Учебный проект по созданию базовой складской конфигурации в 1С:Предприятие 8. Реализован учёт остатков товаров через регистр накопления, документы «Поступление» и «Реализация».

## Возможности
- Учёт остатков по номенклатуре (регистр `ОстаткиТоваров`).
- Поступление товаров: документ `Поступление`, приход на склад.
- Реализация товаров: документ `Реализация`, расход со склада.
- Движения по регистру накопления при проведении документов.

## Структура конфигурации
- Регистр накопления: `ОстаткиТоваров` (измерения: Номенклатура, Склад; ресурс: Количество).
- Документы:
  - `Поступление` — приход.
  - `Реализация` — расход.
- Справочники: `Товары`, `Контрагенты`.

## Как запустить
1. Открыть конфигурацию в режиме «Конфигуратор».
2. Обновить конфигурацию базы данных.
3. Запустить в режиме «1С:Предприятие».
4. Создать тестовые элементы справочников (Номенклатура, Склады).
5. Оформить документы «Поступление» и «Реализация» для проверки учёта.

## Особенности реализации
- Движения формируются в процедуре `ОбработкаПроведения`.
- При проведении `Реализация` не проверяется достаточность остатков.
- При перепроведении старые движения не очищаются (`Движения.ОстаткиТоваров.Очистить()`).

## Требования
- Платформа 1С:Предприятие 8.3.20+ (или совместимая версия).
- Режим работы: Конфигуратор + 1С:Предприятие.
